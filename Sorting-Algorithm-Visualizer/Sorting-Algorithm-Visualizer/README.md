# Sorting Algorithm Visualizer

An interactive web-based Sorting Algorithm Visualizer built using HTML, CSS, JavaScript, and Data Structures & Algorithms.

## Features

- 6 sorting algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
- Adjustable array size
- Adjustable sorting speed
- Random array generation
- Reset functionality
- Comparison counter
- Execution time measurement
- Animated sorting visualization
- Algorithm complexity table
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Data Structures and Algorithms
- DOM Manipulation
- Async/Await
- Performance API

## How to Run

No installation is required.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

For development, you can also use the Live Server extension in VS Code.

## How It Works

The application generates a random numeric array and represents each value as a vertical bar.

When an algorithm is selected and Start Sorting is clicked, the selected algorithm processes the array while the bars are updated in real time.

The application tracks:

- Number of comparisons
- Execution time
- Current algorithm

## Complexity

| Algorithm | Best | Average | Worst | Space |
|---|---|---|---|---|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) | O(1) |
